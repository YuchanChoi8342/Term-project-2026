# 과제 안내문 린터: 요구사항 누락·모호성 탐지기

오픈소스 소프트웨어 텀프로젝트 제안서 | Python 기반 과제 안내문 점검 프로그램

## 1. 프로젝트 개요

본 프로젝트는 과제 안내문을 분석해 요구사항을 정리하고, 사용자가 제출 전에 누락된 항목을 확인할 수 있도록 돕는 파이썬 기반 도구를 개발하는 것을 목표로 한다. 여기에 더해, 코드 린터가 코드의 문제를 미리 짚어주듯 안내문 자체의 문제(모호한 표현, 서로 모순되는 조건, 빠진 정보)를 찾아 알려준다. 학생은 제출 전 점검에, 출제자는 안내문을 배포하기 전 점검에 같은 도구를 사용할 수 있다.

## 2. 개발 동기 및 문제 정의

과제 안내문은 자연어로 작성되어 요구사항이 여러 문단에 흩어져 있는 경우가 많다. 학생은 이를 직접 읽고 기억하면서 구현해야 하므로, 프로그램이 정상 작동해도 필수 조건이나 제출 파일을 빠뜨릴 가능성이 있다. 일반적인 체크리스트는 사용자가 모든 항목을 직접 작성해야 한다는 한계가 있다.

또한 요구사항 누락은 학생만의 문제가 아니다. "적절히", "충분히"처럼 기준이 불명확하거나 서로 충돌하는 조건이 안내문에 들어 있으면 학생이 성실히 읽어도 오해가 생긴다. 본 프로젝트는 요구사항 후보를 정리하는 데서 더 나아가, 안내문에서 해석이 갈릴 수 있는 부분을 함께 짚어준다.

## 3. 주요 기능

- **과제 안내문 입력**: 과제 설명을 텍스트로 붙여 넣거나 텍스트 파일로 불러온다.
- **요구사항 후보 추출**: 'must', 'should', 'include', 'submit', '사용해야 한다', '제출한다' 등 조건을 나타내는 표현 주변의 문장을 찾아 후보 목록으로 제시한다.
- **안내문 점검(린트)**: 다음 항목을 검사해 경고로 표시한다.
  - 모호한 표현 탐지: '적절히', '충분히', '가능하면' 등 기준이 불명확한 표현을 찾고, 출제자에게 물어볼 확인 질문 목록을 만들어 준다.
  - 조건 충돌 탐지: '최대 3개'와 '5개 이상'처럼 숫자 조건이 서로 맞지 않는 경우를 찾는다.
  - 누락 정보 탐지: 마감일, 제출 방법, 제출 형식이 안내문에 있는지 확인한다.
- **체크리스트 생성 및 편집**: 추출한 문장을 사용자가 확인하고 항목을 추가·수정·삭제한다.
- **완료 상태 점검**: 각 요구사항을 완료·미완료로 표시하고 미완료 항목과 전체 진행률을 보여준다.
- **결과 출력**: 학생용으로는 미완료 항목을 모은 제출 전 점검 보고서를, 출제자용으로는 안내문 점검 보고서를 텍스트 파일로 저장한다.

### 두 가지 사용 방식

- **학생**: 안내문을 입력해 요구사항 목록을 만들고, 제출 전 미완료 항목을 점검한다.
- **출제자**: 안내문 배포 전에 모호한 표현과 조건 충돌, 누락 정보를 확인해 안내문을 수정 및 점검한다.

## 4. 구현 방법 및 사용 기술

Python의 문자열 처리, 정규표현식, 조건문, 반복문, 리스트와 딕셔너리를 사용해 요구사항 후보 추출과 안내문 점검을 구현한다. 모호한 표현은 단어 사전과 대조해 찾고, 숫자 조건 충돌은 숫자와 비교 표현을 정규식으로 뽑아 비교한다. 파일 입출력으로 안내문과 점검 결과를 저장하며, 필요하면 간단한 GUI 또는 웹 화면을 추가할 수 있다. 자연어를 완벽하게 이해하는 인공지능을 만드는 대신, 키워드와 문장 분리 규칙으로 후보를 제시하고 최종 판단은 사용자가 하도록 설계한다. 따라서 구현 범위를 통제하면서도 실제 사용 가능한 프로그램을 만들 수 있다.

## 5. 차별성 및 기대 효과

기존 체크리스트가 사용자가 입력한 항목의 완료 여부만 관리한다면, 본 프로그램은 안내문 자체를 점검 대상으로 삼는다. 요구사항 후보를 먼저 찾아 제시하고, 안내문의 모호함과 모순까지 알려준다는 점이 차별점이다. 같은 도구를 학생과 출제자가 모두 사용할 수 있어 활용 범위도 넓다. 이를 통해 요구사항을 기억에만 의존하지 않고 체계적으로 관리하게 하며, 사소한 누락과 안내문 해석 차이로 인한 오해와 감점을 줄이는 데 기여할 수 있다.

## 6. 개발 범위 및 향후 개선

초기 버전에서는 텍스트 입력, 키워드 기반 후보 추출, 안내문 점검(모호한 표현·조건 충돌·누락 정보), 체크리스트 편집, 완료 상태 저장, 미완료 항목 요약 기능을 구현한다. 이후 과목별 템플릿, 코드 파일 이름 검사, README·보고서 제출 여부 확인, 특정 프로그래밍 언어의 필수 키워드 존재 여부 검사 등을 추가할 수 있다. 또한 핵심 엔진이 "문서에서 의무 조건을 찾아 이행 여부를 점검한다"는 구조이므로, 향후 입시 모집요강, 공모전 공고, 장학금 신청 안내문 등으로 적용 범위를 확장할 수 있다. 단, 키워드 추출만으로 모든 요구사항을 자동 판별할 수는 없으므로 사용자의 검토 과정을 필수 단계로 둔다.
